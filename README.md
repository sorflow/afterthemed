# AfterThemed

AfterThemed is a Windows x64 DVAUI theme editor for Adobe After Effects. It can customize validated `dvaui.dll` color and font structures and theme detected CEP HTML/CSS panels with verified, restorable backups.

## Latest installer

- [AfterThemed Setup 1.3.1](https://github.com/sorflow/afterthemed/releases/download/v1.3.1/AfterThemed-Setup-1.3.1.exe)
- Platform: Windows x64
- SHA-256: `748C08B9480CAAF93DBB6686EC1131FB3E8C3E83F5DA3597A7AD6D12806BF410`

Close After Effects before installing or applying a theme. To update Flow, Kease, Curves, and other detected CEP panels, open **Panels & Font** and select **Apply Panels Now**, then restart After Effects.

Version 1.3.1 adds signed CEP bundle theming through Adobe CEP developer mode, persistent runtime palette overrides for host-theme scripts, CSS-in-JS and inline SVG colors, ordinary canvas-stroke theming, and byte-exact restore behavior.
